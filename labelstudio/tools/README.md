# How to use the tool scripts for our LabelStudio?

1. You need to have `uv` for python installed. [Install here](https://docs.astral.sh/uv/getting-started/installation/)
2. go inside the tools folder

```
cd naoth-deeplearning/labelstudio/tools
```

3. run the script with uv:

```
uv run <SCRIPT_NAME>.py
```
